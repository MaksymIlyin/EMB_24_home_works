# Homework

This repository contains my programming homework and exercises.

## Structure

```text
.
├── src/
│   └── main.cpp
│
├── home_works/
│   ├── hw1_1.cpp
│   ├── hw1_2.cpp
│   └── hw1_3.cpp
│
└── ...
```

### Files

* `src/main.cpp` — the most recent homework assignment.
* `home_works/` — previous homework assignments, kept for reference.
* `home_works/hw1_3.cpp` — a specific homework assignment.

The `main.cpp` file is used as the current working assignment. Once a new assignment is started, the previous one can be moved to `home_works/` and named according to its homework number.

## Homework Naming

Homework files follow this convention:

```text
hw<homework>_<task>.cpp
```

For example:

```text
hw1_1.cpp
hw1_2.cpp
hw1_3.cpp
hw2_1.cpp
```

This makes it possible to identify the homework number and task directly from the filename.
